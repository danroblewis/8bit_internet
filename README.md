# 8-BIT INTERNET

A Chrome extension that turns every web page into a neon 8-bit video game. It doesn't just
swap fonts: the whole rendered page goes live through an SVG filter pipeline on the GPU, so
scrolling, video and animations all stay pixelated at 60fps.

## Install (for your friend)

1. Unzip `dist/8bit-internet.zip` (or use the `extension/` folder directly).
2. Open `chrome://extensions`, turn on **Developer mode** (top right).
3. Click **Load unpacked** and pick the unzipped folder.
4. Pin the space-invader icon. Click it for the options menu. **Alt+Shift+8** toggles power.

## Try it here

```sh
npm install
npm start                     # opens Chrome with an isolated profile + the extension
npm start https://github.com  # ...or start on any URL
```

## What it does

**Rendering (live, no screenshots)**
- `<html>` gets an SVG filter: dark-mode flip (on light pages only) → palette grade →
  ordered 4×4 Bayer dither → quantize to the palette.
- Images, video, canvas and video embeds get a mosaic pixelate filter plus a counter-matrix,
  so photos keep their real colors after the page filter runs over them.
- Palettes: **NEON**, **SYNTHWAVE**, **CGA**, **GAME BOY**, **NES**, **VIRTUAL BOY**, **1-BIT**.
- Pixel fonts (Press Start 2P, Silkscreen, Pixelify Sans, VT323), sized with `font-size-adjust`
  so layouts don't blow up. Square corners everywhere. Neon headings with hard drop shadows.
- **CHUNKY TEXT** mode pixelates everything, text included, with box-averaged blocks.

**Scroll effects**
- Images resolve from huge blocks down to sharp pixels as they enter the viewport (SNES mosaic).
- Headings type themselves in; paragraphs step up into place.
- Scroll fast and the screen RGB-splits along the scroll axis (warp).
- Parallax pixel starfield behind the page, a demoscene sine-wave scroller on the first screen,
  and a CRT layer with scanlines, vignette and a rolling refresh band.

**Game layer**
- HUD: score (earned by scrolling and clicking), per-site hi-score, WORLD number, current
  "stage" (section heading), progress bar and FPS.
- "WORLD 4-3" intro with a pixel iris wipe (full version once per site per tab).
- "COURSE CLEAR!" when you reach the bottom of a long page.
- Pixel cursor, particle bursts and "+100" on click, and chiptune SFX from WebAudio square
  waves (off by default; toggle **SND** in the HUD).
- ↑↑↓↓←→←→BA.

## Layout

```
extension/
  manifest.json      MV3; content script runs at document_start in all frames
  shared.js          palettes, defaults (shared by content script, popup, worker)
  content/bit8.js    the whole effect: filters, CSS, overlay HUD, FX, sound
  popup/             8-bit options menu (arrow keys work)
  background.js      badge + Alt+Shift+8 toggle
  fonts/             OFL-licensed pixel fonts from Google Fonts
  icons/             generated by tools/make-icons.mjs
tools/               puppeteer harnesses used for testing (tour, perf, debug, ...)
```

## Notes and limits

- Light pages get flipped dark. Pages that are already dark keep their brightness and only
  get the palette.
- Cross-site iframes render out of process, where the parent's SVG filter can't reach, so the
  content script also runs inside them and filters them itself ("frame mode").
- Icon fonts are skipped by class-name heuristics (`icon`, `fa-`, `material`, ...). An
  unusual icon font could still get swapped for a pixel font. Set FONTS to ORIGINAL if so.
- Honors `prefers-reduced-motion`: no reveal animations, warp, scroller or intro.
- `chrome://` pages and the Chrome Web Store can't be touched by any extension.
